What happens

  1. 1
    Before the lineThe scroll position is less than the header height. The header stays, so nothing hides yet.
  2. 2
    Scrolling down past the lineThe scroll position is past the header height and the user keeps going down. The header slides off.
  3. 3
    Scrolling upThe user scrolls up by any amount. The header slides back in right away, from any position.

Why this standard

Hiding only after the header height keeps the header visible while the user is still near the top. Showing it on any scroll up means Back and navigation are always one small scroll away, so the user never has to return to the top to use them. This is a suggested standard. The scroll distance and whether to hide at all depend on the app experience.
